# 💡 MindScape – Modern Blog UI


A sleek, responsive, and animated blog platform built **entirely with vanilla HTML, CSS, and JavaScript** — no frameworks, no dependencies. Designed for developers and creatives who value clean code and beautiful UX.

🔗 **[Live Demo](https://msalimimaram.github.io/MindScape/)**

---

## 🌟 Features

- ✅ **Fully Responsive** – Works flawlessly on mobile, tablet, and desktop
- ✅ **Smooth Animations** – Scroll-triggered fade-ins, hover effects, floating hero image
- ✅ **Dynamic UI** – Auto-hiding header, back-to-top button, mobile menu
- ✅ **Modern Design System** – CSS variables, gradients, shadows, and typography
- ✅ **Interactive Elements** – Newsletter forms, search icon, category cards
- ✅ **Optimized Performance** – Lightweight (~50KB total), no external JS libraries
- ✅ **Pixel-Perfect Layout** – Grid, Flexbox, and CSS architecture best practices

---

## 🛠️ Tech Stack

| Layer        | Technology               |
|--------------|--------------------------|
| Structure    | HTML5                    |
| Styling      | CSS3 (Custom Properties, Grid, Flexbox, Animations) |
| Interactivity| Vanilla JavaScript (DOM, Events, Intersection Observer) |
| Fonts        | Google Fonts (`Poppins`, `Playfair Display`) |
| Icons        | Font Awesome 6           |
| Hosting      | GitHub Pages             |
